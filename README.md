# 수문장(水門將) — WARDEN OF WATERS

동양풍 다크 판타지 카드형 전략·정치 시뮬레이션. 게임 규칙과 판정은 모두 Java 백엔드에서 처리하고, React는 화면 표시와 입력만 맡는다.

## 게임 규칙
### 한 판의 진행과 제한 시간

1. 게임을 시작하면 회사 지표, 인물, 파벌, 시설, 카드와 회차 해금 효과를 준비한다.
2. 게임은 하루 단위로 진행한다. **7일마다 해결해야 할 카드가 주어지며, 각 카드에는 해결 제한 시간이 있다.**
3. 플레이어는 카드 종류와 등급을 확인한 뒤, 조건에 맞는 사건·대상을 찾아 카드를 사용한다.
4. 제한 시간 안에 카드를 해결하지 못하면 원작처럼 게임이 끝난다. 수문장에서는 이에 대응하는 실패 엔딩으로 연결한다.

카드는 명령권이다. 대표를 제외한 사람은 명령을 거부할 수 없지만, 카드가 악행의 결과까지 없애 주지는 않는다. 사건에서 인물에게 원한을 사거나, 정치적 역풍을 맞거나, 판정에 실패해 대가를 치를 수 있다. 술탄이 사건에 직접 관여하면 별도의 규칙을 내세울 수도 있다.

### 카드의 종류와 등급

원작 카드에는 **4종류**와 **4등급**이 있다.

| 종류 | 해결해야 하는 행동의 예 |
|---|---|
| 살육 | 사람 또는 사람에 준하는 지성을 가진 대상을 죽인다. 술탄의 명령으로 죽이면 일부 사건에서 죄의 증거를 남기지 않는다. |
| 색욕 | 조건에 맞는 인물을 대상으로 관계를 맺는다. 대상이 망신을 당하거나 떠나고, 보복을 시도할 수 있다. |
| 탕진 | 사치나 과소비 등 재산을 낭비한다. 일반 지출 사건에서 비용을 늘리는 대신 카드를 해결하는 경우도 있다. |
| 정복 | 토벌, 전쟁, 사냥, 모험 등 사건이나 장소를 정복한다. 군대와 추종자는 카드와 별도로 준비해야 한다. |

| 등급 | 순서 |
|---|---:|
| 금 | 가장 높음 |
| 은 | 2위 |
| 동 | 3위 |
| 돌 | 가장 낮음 |

**대상의 등급은 카드 등급과 같거나 높아야 한다.** 따라서 금 카드는 금 대상에게만 쓸 수 있고, 동 카드는 동·은·금 대상에게 쓸 수 있다. 카드 등급은 인물 능력치만으로 정해지지 않으며, 사건에 따라 바뀔 수 있다. 등급과 능력치·태그는 서로 다른 정보다.

사건마다 허용하는 카드 종류, 대상, 비용, 판정이 다르다. 정복처럼 인물이 아니라 장소나 사건을 대상으로 하는 카드도 있다. 사건에 카드가 접수되는 것과 사건 판정에 성공하는 것은 별개로 처리한다.

### 수문장의 고정 사건 5개와 재사용 규칙

- 수문장은 주요 카드 해결 경로로 **고정 사건 5개**를 둔다. 각 사건은 받을 수 있는 카드 종류와 등급, 대상 조건, 비용·판정, 성공·실패 결과를 가진다.
- **같은 사건에서 같은 카드 종류·등급 조합은 한 번만 카드를 깬다.** 같은 조합을 다시 사용하는 시도는 가능하지만, 두 번째부터는 카드가 깨지지 않고 손에 남는다. 따라서 해당 카드로 제한 시간 과제를 해결한 것으로 계산하지 않는다.
- 제한은 사건과 카드 조합에 적용된다. 다른 사건이 그 카드를 받을 수 있고 카드 사본이 남아 있다면, 그 사건에서 해결을 시도할 수 있다.
- 원작의 일부 인물 대상 사건은 카드 조합 제한과 별개로 같은 대상에게 한 번만 사용할 수 있다. 특히 살육·색욕은 대상의 등급이 바뀌지 않는 한 같은 인물에게 반복할 수 없다.

예를 들어 은 등급 살육 카드로 사건 A에서 금 등급 인물을 처치했다면, 사건 A에서 같은 은 등급 살육 카드를 다시 깨지는 못한다. 다른 카드 사본을 다시 제시할 수는 있지만 카드가 소모되지 않으며, 카드 해결 과제도 완료되지 않는다. 사건 B가 은 등급 살육을 허용한다면 남은 사본을 사건 B에 사용할 수 있다.

### 능력치, 태그, 판정

- 인물의 등급은 카드 대상 자격을 정한다. 능력치는 사건의 능력치 판정에 사용한다.
- 태그는 인물의 신분과 특성을 나타내며, 사건 참여 가능 여부를 바꾼다. 예를 들어 특정 신분만 들어갈 수 있는 장소나 의식이 있을 수 있다.
- 명성이나 정치 지표는 사건의 발생·억제와 선택지 해금에 영향을 준다. 수문장에서는 회사 지표, 파벌 태도, 인물 관계가 이 역할을 맡는다.
- 능력치 판정에 실패해도 카드 사용으로 생긴 사건의 대가는 사라지지 않는다. 성공·실패 효과는 사건 데이터에 따로 정의한다.

### 운명의 상점 — 다회차 해금

운명의 상점은 한 판이 끝난 뒤에도 유지되는 해금 요소다. 원작은 카드 해결과 특정 엔딩으로 얻은 운명점을 사용해 다음 회차의 시작 조건과 선택지를 강화한다. 수문장에서는 같은 구조를 **운명의 상점**으로 가져오되, 캐릭터와 아이템 이름 및 비용은 수문장 세계관에 맞춘다.

| 해금 묶음 | 다음 회차에 주는 효과 |
|---|---|
| 동료 추가 | 새 인물을 시작 멤버나 추종자로 합류시킨다. |
| 주인공 강화 | 시작 능력치나 특성을 높인다. |
| 동료 강화 | 특정 인물의 등급이나 능력치를 높인다. |
| 시작 자원·소지품 | 시작 예산, 장비, 편의 아이템을 추가한다. |
| 게임 규칙·콘텐츠 | 새 이야기와 사건을 열거나, 카드 교환·턴 되돌리기 같은 회차별 사용 횟수를 늘린다. |

원작에서는 술탄 카드를 해결할 때마다, 또는 **천일야화**를 달성할 때 운명점을 얻는다. 수문장도 카드 해결과 특정 회차 목표 달성에 보상을 연결하고, 보상량은 별도로 조정한다. 상점에서 구매한 영구 해금은 다음 게임을 만들 때 시작 상태에 반영하고, 카드 교환·턴 되돌리기처럼 사용 횟수가 있는 효과는 매 회차 초기화한다.

### 현재 코드와의 차이

위 규칙은 설계 기준이며 아직 코드에 전부 구현되어 있지 않다. 현재 `CardType`은 `WORK`와 `DECREE`, 특별지시 종류는 `PURGE`·`APPEASE`·`CONSCRIPT`·`SEIZE`로 정의되어 있다. 등급 Enum에는 원작의 네 등급 외에 수문장 전용 `PRESIDENT`도 있으므로, 이를 다섯 번째 카드 등급으로 취급하지 않고 별도 해금 카드로 다룬다. 원작의 카드 4종류·등급 판정·제한 시간·사건별 재사용 기록·회차 해금 상점은 별도로 연결해야 한다. 현재 능력치 판정은 수문장의 JSON 형식에 맞춘 0~100 기준을 유지한다.

## 구성

| 경로 | 내용 |
|---|---|
| `src/main/java/.../domain/*` | 도메인별 controller / dto / entity / repository / service |
| `src/main/java/.../global` | 공통 설정(CORS), 예외 처리, 공통 응답(`ResultDto`), 공용 Enum |
| `src/main/java/.../data` | game-data JSON 로더·검증기 |
| `src/main/resources/game-data` | 기본 콘텐츠 JSON (형식: `docs/game-data-format.md`) |
| `frontend/` | React + TypeScript + Vite + Tailwind CSS |
| `compose.yaml` | 개발용 PostgreSQL |

## 실행

백엔드 (H2 인메모리, 설치 없이 바로 실행):

```bash
./gradlew bootRun
```

백엔드 (PostgreSQL):

```bash
docker compose up -d
./gradlew bootRun --args='--spring.profiles.active=postgres'
```

프론트엔드 (http://localhost:5173):

```bash
cd frontend && npm install && npm run dev
```

테스트:

```bash
./gradlew test
```
